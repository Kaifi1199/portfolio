# Muhammad Kaif — Portfolio

Next.js 14 (App Router) + Tailwind CSS 3, animated with GSAP + ScrollTrigger, anime.js v4, Framer Motion and Lenis.

    npm install
    npm run dev

Edit your content in `data.ts` (projects, experience, skills, education, contact links).
Colours and fonts live in `tailwind.config.js`.
